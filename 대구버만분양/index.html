04

방문 예약부터 사후관리까지

분양 전 건강 확인은 예비 보호자가 동물병원에 직접 가서 합니다. 그 결과를 보고 계약합니다.

  1. SNS·전화로 방문 예약

    버만 상담은 전화나 카톡으로 방문 날짜부터 잡습니다.

  2. 1:1 맞춤 상담

    매장에서 버만의 성격과 생활 습관을 직접 보고, 집 환경에 맞는지 펫플래너와 함께 판단합니다.

  3. 동물병원 건강 확인

    버만 건강은 예비 보호자가 동물병원에서 기본검사로 직접 확인합니다.

  4. 계약서 작성·주의사항

    버만 계약서에는 상태와 주의사항을 적고, 사료 급여와 적응 기간을 설명합니다.

  5. 분양 후 사후관리

    버만을 데려간 뒤에도 궁금한 점은 전화·SNS로 물어보시면 됩니다. 사후관리는 추가 비용이 없습니다.

방문 전 예약하면 1:1로 상담합니다.

05

대구에서 오시는 분께

대구에서 오시는 분도 대구점에서 버만을 직접 보고, 성격과 생활 습관 설명을 들은 뒤 결정합니다.

대구 보호자님이 많이 묻는 것은 건강 확인과 사후관리입니다. 건강은 동물병원에서 직접 확인하고, 분양 뒤 상담은 추가 비용이 없습니다.

대구에서는 대구점(남구 대명동)으로 방문 예약 후 오시면 됩니다.

홈딜리버리 순서

  1. 매장 방문 후 상담·분양 결정
  2. 출발 전 아이 상태 확인 사진 촬영·첨부
  3. 배송 날짜 지정
  4. 분양 관련 서류 지참해 출발
  5. 집 앞 도착
  6. 계약서 작성·주의사항 설명 후 완료
06

    분양 뒤 사후관리·후케어를 추가 비용 없이 돕습니다.

  • 합법적인 분양 절차

  • 건강 상태 확인

    입양 전 예비 견주·묘주님이 직접 기본검사로 건강 상태를 확인한 뒤 분양합니다.

07

버만 키우기, 많이 묻는 세 가지

버만 털 날림이 걱정돼요
버만의 털 빠짐은 보통입니다. 공기청정기와 정기 빗질로 날림을 줄이고, 걱정되면 상담 때 털이 덜 빠지는 품종을 함께 봅니다.
버만 화장실은 어떤 걸 쓰나요?
몸이 들어가 한 바퀴 돌 수 있는 크기를 고르고, 처음엔 매장에서 쓰던 모래 종류를 맞춰 줍니다.
버만 스크래처가 꼭 필요한가요?
발톱을 가는 건 본능이라 세로형·가로형을 하나씩 두면 가구 긁는 일이 줄어듭니다.
08

자주 묻는 질문

방문은 예약해야 하나요?

네. 전화, 오픈카톡, 인스타그램 DM으로 예약하면 예약 시간에 1:1로 상담합니다.

분양 뒤에도 상담해 주나요?

분양 후 사후관리·후케어를 추가 비용 없이 돕습니다. 전화·SNS로 문의하시면 됩니다.

대구까지 데려다주나요?

매장 상담으로 분양을 정한 뒤 홈딜리버리를 신청하면, 출발 전 상태 사진을 보내고 지정한 날짜에 집 앞에서 계약서와 주의사항을 안내합니다.

버만 건강 확인은 누가 하나요?

예비 견주·묘주님이 동물병원에 직접 가서 기본 건강검진으로 확인한 뒤 분양합니다.
